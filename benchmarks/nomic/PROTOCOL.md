# Frozen Nomic benchmark method v2 — pre-measurement label audit

67 curated synthetic evidence-linked episodes; 99 queries: 24 development, 75 held-out test. Three correction, three forgetting and three expiry fixtures. Every summary is a fixture-authored **reported** narrative attached through the unchanged memory API, not an automatic-consolidation result. All source events and labels are synthetic, never real user history.

Freeze `fixtures.json`, `GROUND_TRUTH.md` and this protocol by hash/commit **before any model scores**. Greg independently audits labels. No edits or parameter tuning based on held-out metrics; an invalid dataset requires a new explicitly versioned evaluation, not rewritten results.

- Five rows: FTS5; installed v1.5 semantic; installed v2 semantic; FTS5+v1.5; FTS5+v2. The quantizations differ, so compare installed configurations only.
- Same final corpus, eligible document set, k=5, filters, source clock, lifecycle state and repeat count. Return Recall@1/3/5 and MRR from accepted `retrieved_ids`, with unthresholded `ranked_ids` also available. All rows include `expected_ids` so independent arithmetic is possible.
- Domain/session filters are declared question context, not inferred model capabilities. No per-backend filter advantage. Temporal prompts distinguish dated and latest-recorded history; present-tense live state is always unknown without fresh world observations.
- No generation step exists. All returned text is exact retained memory text with evidence IDs, revision, truth kind and uncertainty. Similarity is relevance, not factual confidence. `contested` remains unimplemented v0.2; the fixtures label conflicting reports as unresolved and require both where appropriate.
- FTS uses the unchanged v0.1 literal-token/BM25 policy. Semantic uses full 768-dimensional normalized vectors and cosine; hybrid uses reciprocal-rank fusion with constant60 and at most100 ranked candidates per lane (the eligible corpus is smaller). No reranking LLM or hidden model-specific budget.
- Abstention thresholds are selected **only from the 24 dev cases**. Candidate thresholds are the observed dev top scores plus endpoints, optimizing balanced answerability accuracy; ties prefer more conservative rejection. FTS gate uses top raw BM25 relevance; semantic and hybrid use top cosine, calibrated once per installed embedding space. Record thresholds and dev score rows before evaluating test labels. Never choose a threshold from test output.
- Live-state assertion guard always returns current-world state unknown and tags retrieved history as historical. It does NOT erase legitimate historical retrieval hits. Q097/Q098 expect the dated coordinate/door episodes for retrieval and separately require live-state unknown; Q099 is assertion-only with ungraded historical retrieval because it has no unique historical target. Exclude these three from the no-evidence false-retrieval denominator. No-evidence false-retrieval rate, false abstention on supported cases, per-query wrong/missed IDs and temporal/conflict slices are mandatory.
- Measure query embedding and retrieval latency separately, at least3 repeats; report median/max and loaded-model/resource conditions. Indexing time includes document embedding and index construction, with separately logged timings. Record cache/warm/cold conditions; no fake cold-run claim.
- All ASCII document/query inputs plus prefix are <=400 bytes; verify actual tokenizer/usage against the primary <=512-token limit if exposed. No long-context comparison in the primary run. Verify actual prefix behavior before corpus encoding, store raw probe outputs and prevent double prefixes.
- Lifecycle before/after uses the same three selected public operations per class; old correction text/vectors must not be served, forgotten/expired IDs must be absent. Keep evidence and derived/index cleanup checks distinct from a semantic threshold's incidental rejection.

Audit corrections were made before any model scores: all target episode IDs are disjoint across dev/test; E001 is held-out only; Q056's comparative answer requires both E055/E056 without a date filter excluding either. Q059/E059 is retrievable withdrawal/correction evidence, not a no-evidence query. JSON tags contain no punctuation suffixes; keyword-control cases are tagged explicitly.

Retention is exactly2592000 seconds (30 days). The fixed synthetic clock advances from 2026-10-22T12:00:00Z to 14:00:00Z. Assert exactly E061/E062/E066 expire and E063/E064/E067 are forgotten before any final measurements; every other expected target remains reachable. Failure aborts the benchmark rather than scoring a backend miss.

Source model artifacts, quantization, hashes, instance/load configuration, actual dimensions and prefix behavior must be recorded per index. Do not silently reuse a cache from another model/configuration.
